2. TUJUAN SISTEM LAPTOP
================================================================================
Membangun antarmuka desktop/laptop (resolusi standar 1280 × 720 atau layar penuh desktop) untuk pemilik warung, yang mencakup:
1. Autentikasi Pemilik (Login Email/Password & Google Sign-In).
2. Layout Desktop Khusus: Sidebar permanen (kiri), Top bar dengan filter rentang waktu (kanan atas), dan Konten berbasis tabel & kartu split-view.
3. 8 Layar Utama:
   - Masuk (Login)
   - Home (Dashboard KPI, grafik batang per jam, daftar transaksi terbaru)
   - Riwayat (Split-view tabel transaksi & panel detail struk, dialog ekspor Excel/PDF/CSV, share, unduh PNG)
   - Menu (Split-view tabel katalog menu & panel edit menu, dialog tambah menu)
   - Menu Pelanggan (Pengaturan kasir tablet, prioritas kategori maks 7 item, pengaturan Terlaris, dialog pratinjau kasir)
   - Kasir (Kartu profil kasir, dialog tambah kasir, ubah nama, hapus kasir)
   - Laporan (KPI mingguan, grafik batang per hari, daftar menu terlaris)
   - Pengaturan & Akun (Profil kafe, backup data JSON, ganti password, palet tema & warna, dialog cetak menu A4)
4. Fitur Cetak Menu A4 (1 sampul + 3 halaman kategori, margin normal/4433, mode hemat tinta, terhubung ke window.print()).

================================================================================
3. ATURAN GAYA & KONSISTENSI DESAIN (GOLDEN STANDARD)
================================================================================
1. HIERARKI TEKS (7 SKALA TETAP):
   - --t-xs / --l-xs (12px / 16px): label kecil, tanggal, badge status.
   - --t-sm / --l-sm (14px / 20px): teks isi sekunder, tabel, tombol kecil.
   - --t-md / --l-md (16px / 24px): teks isi default, baris tabel, tombol utama.
   - --t-lg / --l-lg (20px / 28px): sub-heading panel, judul kartu detail.
   - --t-xl / --l-xl (32px / 40px): heading layar utama (h2).
   - --t-2xl / --l-2xl (44px / 52px): angka KPI omzet besar, branding login.
   - --t-3xl / --l-3xl (64px / 72px): kembalian / display angka jumbo.
   - Bobot font: 500 (reguler), 700 (semi-bold), 800 (tebal judul).

2. GRID & KONTROL:
   - Semua jarak, padding, gap, dan ukuran kelipatan 4px.
   - Tinggi kontrol tombol & input standar desktop: 40px, 48px, 56px.
   - Posisi filter rentang waktu: selalu tetap di pojok kanan atas top bar.

3. BENTUK & SUDUT (RADIUS):
   - Radius 12px (var(--r-sm)): chip kecil, badge status.
   - Radius 16px (var(--r-md)): input form, tombol kontrol, thumbnail menu.
   - Radius 24px (var(--r-lg)): panel sidebar, kartu detail, kontainer konten.
   - Radius 32px (var(--r-xl)): dialog modal, toast notifikasi, avatar.
   - Pil 999px: tombol rentang waktu, chip navigasi.

4. MATERIAL LAPISAN:
   - Frosted Acrylic (.g-acrylic / .g): Panel sidebar, kartu dashboard KPI, kartu rincian transaksi, panel pengaturan.
   - Liquid Glass (.g-liquid / .g.sh): Dialog modal melayang, popover akun, toast status melayang.
   - Baris & Kontrol Input: Datar (flat) tanpa blur.

5. ATURAN SATU TOMBOL LIME:
   - Hanya boleh ada MAKSIMAL 1 tombol berlatar hijau terang (Lime Accent) per layar aktif untuk aksi terpenting.
   - Tombol sekunder harus menggunakan varian datar (.tk-btn-flat / .bay.g).

--- 4.10. FITUR CETAK MENU A4 (BAGIAN 11) ---
- Dihasilkan dari data menu asli Supabase.
- Tata letak A4 presisi: 1 lembar sampul depan + 3 lembar kategori isi.
- Opsi Margin: "Margin normal" (2,54 cm) vs "Margin 4433" (kiri 4 cm, atas 4 cm, kanan 3 cm, bawah 3 cm).
- Opsi Hemat Tinta: latar putih bersih vs latar gelap penuh.
- Tombol "Cetak menu" memicu print preview browser (A4 portrait).
